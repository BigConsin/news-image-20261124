A Python program that writes a one-image newspaper front page summing up the world news of Tuesday 24 November 2026 — 36 stories from 7 regions on one page: the unwinding of Monday's Nvidia-led chip rally, Sanofi's $41bn takeover of Insmed, the Zaporizhzhia strike toll, the Kremlin shutting Europe out of Ukraine talks, 175 migrants missing off Senegal, US consumer confidence at a near-two-year high, and England's T20 rout of Australia — to /output/entry.png. The page is typeset programmatically (draw_image.py + stories.py) so every story reads clearly in the single image.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
